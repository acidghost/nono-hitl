New requests show up here and as a notification. Unanswered requests are denied at their deadline.

Help

  • Unanswered requests are denied at their deadline. Missing one never approves it.
  • Approve once covers this invocation only. Approve for session also covers later requests from the same nono session with exactly the same command, argument array, caller and rule, until you revoke it.
  • Approving lets nono run the command in the child sandbox set by the profile. It adds no permissions.
  • Decisions are kept in memory and cleared when the service restarts.
  • Approve keys work one second after a request appears, and only after a pause in typing, so text meant for the terminal can't approve anything.
  • Listening on 127.0.0.1. Run this service outside the agent sandbox.
